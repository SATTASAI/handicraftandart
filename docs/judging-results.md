# กรรมการ ผลการแข่งขัน และประกาศนียบัตร

## ลำดับการทำงาน

1. **มอบหมายกรรมการ** (superadmin): เลือกรายการ แล้วติ๊กบัญชีที่มีบทบาทกรรมการ ผู้ฝึกซ้อมที่เป็นกรรมการด้วยมอบหมายได้ แต่ให้คะแนนทีมที่ตนส่งเองไม่ได้
2. **สำหรับกรรมการ**: กรรมการเห็นเฉพาะรายการที่ได้รับมอบหมาย และเฉพาะทีมที่ยืนยันการลงทะเบียนแล้ว ให้คะแนนตามเกณฑ์ย่อยของรายการ (รายการที่สร้างเองไม่มีเกณฑ์ย่อย ใช้ “คะแนนรวม” เต็ม 100) แก้คะแนนได้ด้วยการบันทึกซ้ำ
3. **ผลการแข่งขัน**: คะแนนทีม = ค่าเฉลี่ยคะแนนรวมจากกรรมการที่ต้องให้คะแนน (ไม่นับกรรมการที่เป็นเจ้าของทีม) จัดอันดับจากมากไปน้อย คะแนนเท่ากันได้อันดับเดียวกัน
   - เหรียญทอง ≥ 80 · เหรียญเงิน 70–79.99 · เหรียญทองแดง 60–69.99 · ต่ำกว่า 60 = เข้าร่วม (คิดเป็นร้อยละของคะแนนเต็ม)
   - อันดับ 1–3 = ชนะเลิศ / รองชนะเลิศอันดับ 1 / รองชนะเลิศอันดับ 2
   - รายการจะประกาศผลอัตโนมัติเมื่อทุกทีมได้คะแนนครบจากกรรมการที่มอบหมาย ก่อนหน้านั้นผู้จัด/superadmin เห็นความคืบหน้าได้ ผู้ใช้อื่นไม่เห็น
   - ถอนกรรมการแล้ว คะแนนของกรรมการคนนั้นไม่ถูกนับ คะแนนผูกกับ revision ของทีม
4. **ประกาศนียบัตร**: ผู้ฝึกซ้อมเห็นเฉพาะทีมที่ตนลงทะเบียน (superadmin เห็นทั้งหมด) เมื่อรายการประกาศผลแล้ว ดาวน์โหลด PDF ได้ทันที 1 ใบต่อนักเรียน 1 คน สร้างในเบราว์เซอร์ (ไม่ส่งข้อมูลออกนอกระบบ) superadmin แก้ชื่อหน่วยงาน ชื่องาน ข้อความวันที่ และผู้ลงนาม (สูงสุด 3 คน) ที่ “ตั้งค่าประกาศนียบัตร”
