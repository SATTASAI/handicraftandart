# ผลตรวจชุดทดสอบปีการศึกษา 2569

ตรวจในวันที่ 2 พฤศจิกายน 2569 โดยใช้ข้อมูลและบัญชีสังเคราะห์ในเครื่อง ไม่มีการส่งอีเมลถึงผู้สมัครจริง

- `npm test`: ผ่าน 9 tests ครอบคลุม Worker/D1 จริงใน Miniflare, การย้าย schema โดยคงบัญชี/ผลคะแนนเดิม, 197 รายการและขอบเขตประถม/อายุ, สิทธิ์ใช้งาน, คุณสมบัติ, ทีมโรงเรียนซ้ำ, กรรมการมีส่วนได้เสีย, จำนวนกรรมการ, คะแนนหัก, คะแนนเต็มดิบ 20, การตัดสิทธิ์, การล็อกเกณฑ์, การคัดลอกรุ่น และการส่งอีเมลแบบจำลองพร้อมกัน/ลองใหม่
- ทดสอบการปิดและเปิด runtime ใหม่แล้ว D1 และรหัสผ่านทดสอบยังคงใช้ได้
- `npm run build`, `npm run test:sites` และ `wrangler deploy --dry-run`: ผ่าน โครงสร้างส่งต่อ Sites เดิมยังอยู่ครบ
- Chromium จริง: หน้าเข้าสู่ระบบ → ค้นหาชุด 197 รายการ → กรองศูนย์การศึกษาพิเศษเหลือ 38 → ลงทะเบียนนักเรียน ป.1 → ผู้จัดกดยืนยันคุณสมบัติ → กรรมการบัญชีแยกเปิดเกณฑ์ 5 หัวข้อและบันทึก 100 คะแนน ไม่มี JavaScript page errors
- ตรวจมือถือขนาด 390×844 ไม่พบหน้าล้นจอ ตารางเลื่อนแนวนอนได้ และปุ่มส่งออกรายชื่อวางหลายแถวได้
- สร้างและเปิด PDF ภาษาไทยจริง แยก 2 หน้าสำหรับนักเรียนและครู ตรวจชื่อเครือข่าย ปีการศึกษา ช่วงอายุ คะแนน และข้อความข้อมูลตัวอย่าง

## สิ่งที่ยังต้องทำในบัญชีจริง

ยังไม่ได้ merge ไป main, apply migrations บน D1 จริง หรือ deploy เว็บจริง สภาพแวดล้อมทำงานไม่มีสิทธิ์ Cloudflare ของเว็บ ตรวจพบเว็บเดิมตอบ health ได้และมี Admin แล้ว แต่ไม่สามารถยืนยัน secret หรือสถานะ Resend ของ Worker จริงได้

ก่อนเผยแพร่ต้องสำรอง D1, ใช้ migrations ตามลำดับ, deploy Worker และทดสอบส่งอีเมลถึงบัญชีของผู้จัดจริง ยังไม่ยืนยัน delivered/bounced จาก Resend และยังไม่มี webhook รับสถานะเหล่านี้

เกณฑ์ปี 2568 ใช้เพื่อทดสอบตามที่ผู้จัดอนุมัติ วันแข่งขัน สถานที่ เพลง/หัวข้อปี 2569 และรายละเอียดการออกประกาศนียบัตรทางการยังไม่ได้ยืนยัน คง `DEMO_MODE=true` ไว้ รวมถึงตรวจข้อจำกัดด้านการชี้ขาดและหน้าที่กรรมการใน [บัญชีเกณฑ์](criteria-2568.md) ก่อนใช้งานทางการ
